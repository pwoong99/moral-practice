# 🌱 도덕 실천 기록장

학생들이 실천 다짐을 등록하고, 정해진 기간 동안 날마다 **O / △ / X** 로 실천 여부를 기록하는 웹앱입니다.
친구들의 실천을 게시판에서 보고 응원 스티커와 한마디를 남길 수 있습니다.

- 화면: GitHub Pages (무료 호스팅)
- 데이터: Firebase Firestore + Authentication (무료 Spark 요금제로 충분)
- 만든이 : 푸르이든

---

## 파일 구성

```
index.html              화면 뼈대
css/style.css           디자인
js/app.js               동작 전체 (학생·교사 화면)
js/firebase-config.js   ★ 내 Firebase 값으로 바꿔야 하는 파일
firestore.rules         ★ Firebase 콘솔에 붙여 넣을 보안 규칙
```

---

## 처음 설치하기 (약 15분)

### 1단계. Firebase 프로젝트 만들기
1. https://console.firebase.google.com 에 접속해 **프로젝트 추가**
2. 이름 예: `moral-practice` → Google 애널리틱스는 꺼도 됩니다.

### 2단계. 웹 앱 등록 → 설정값 복사
1. 프로젝트 개요 화면에서 **웹(`</>`) 아이콘** 클릭 → 앱 닉네임 입력 → 등록
   (Firebase 호스팅 체크는 하지 않습니다. GitHub Pages를 쓸 거예요.)
2. 화면에 나오는 `const firebaseConfig = { ... }` 안의 값을 복사해
   `js/firebase-config.js` 의 `firebaseConfig` 부분에 붙여 넣습니다.

### 3단계. 로그인 방식 켜기 + 교사 계정 만들기
1. 왼쪽 메뉴 **Authentication** → 시작하기 → **로그인 방법** 탭
2. **익명** → 사용 설정 → 저장 (학생 로그인에 씁니다)
3. **이메일/비밀번호** → 사용 설정 → 저장 (교사 로그인에 씁니다)
4. **Users** 탭 → **사용자 추가** → 교사용 이메일과 비밀번호(6자 이상) 입력
5. 그 이메일을 아래 **두 곳에 똑같이** 적습니다.
   - `js/firebase-config.js` 의 `TEACHER_EMAIL`
   - `firestore.rules` 의 `teacherEmail()` 안 `'teacher@example.com'`

### 4단계. Firestore 데이터베이스 만들기 + 규칙 붙여 넣기
1. 왼쪽 메뉴 **Firestore Database** → 데이터베이스 만들기
2. 위치: **asia-northeast3 (서울)** 추천 → **프로덕션 모드**로 시작
3. **규칙** 탭 → 기존 내용을 모두 지우고 `firestore.rules` 파일 내용을 붙여 넣기 → **게시**

### 5단계. GitHub에 올리고 Pages 켜기
1. GitHub에서 **New repository** → 이름 예: `moral-practice` → Public → Create
2. **Add file → Upload files** 로 이 폴더의 파일을 폴더 구조 그대로 끌어다 놓기 → Commit
3. 저장소 **Settings → Pages** → Source: `Deploy from a branch`, Branch: `main` / `(root)` → Save
4. 1~2분 뒤 `https://내아이디.github.io/moral-practice/` 주소로 접속됩니다.

> 💡 `index.html` 을 내 컴퓨터에서 더블클릭해서 열면 동작하지 않습니다(모듈 보안 정책). 꼭 GitHub Pages 주소로 여세요.

### 6단계. 첫 수업 준비
1. 주소 접속 → 아래 **교사 로그인** → 교사 계정으로 로그인
2. **👥 학생 관리** → `1 김하늘` 처럼 한 줄에 한 명씩 붙여 넣고 **명단 등록**
   (엑셀에서 번호·이름 두 칸을 복사해 붙여 넣어도 됩니다)
3. **🖨 비밀번호 쪽지 인쇄** → 잘라서 학생들에게 나눠 주기
4. **🗓️ 회차 관리** → 새 회차 만들기 (이름, 안내 문구, 기간, 1인당 최대 개수, 주말 포함 여부)

## 사용 방법

### 학생
- 번호 고르고 비밀번호 4자리 입력 → **📒 나의 실천**
- **＋ 실천 다짐 추가** 로 실천할 일 등록 (회차마다 최대 개수는 선생님이 정함)
- 날마다 **오늘** 줄의 O / △ / X 버튼으로 기록 (같은 버튼을 다시 누르면 지워짐)
- 깜빡한 지난 날짜는 날짜 칸을 눌러 바꿀 수 있음 (빈칸 → O → △ → X → 빈칸)
- **🏫 우리 반 실천 게시판** 에서 친구 카드를 눌러 응원 스티커 + 한마디 남기기
- 공용 기기에서는 다 쓰고 **나가기** 를 눌러 주세요.

### 교사
- **📊 실천 현황**: 학생별 실천 항목, 오늘 기록, 실천률, 주고받은 응원
  - 학생 줄 클릭 → 기록 수정, 실천 항목 수정·삭제·대신 등록, 응원 삭제
  - **CSV 내려받기**: 날짜별 기록 전체 (엑셀에서 열림)
- **🗓️ 회차 관리**: 여러 회차 동시 진행 가능. **종료하기** 하면 학생은 보기만 가능, **다시 열기** 가능
- **👥 학생 관리**: 이름 수정, 비밀번호 보기·초기화·인쇄, 학생 삭제

### 실천률 계산
지난 날짜(오늘 포함) 기준으로 **O = 1점, △ = 0.5점, X·미기록 = 0점** 을 평균 낸 값입니다.

## 알아 두면 좋은 점

- **보안 수준**: 학생 비밀번호는 4자리 숫자라 학급 활동용 수준입니다. 비밀번호는 학생 화면에서 읽을 수 없도록 규칙으로 막혀 있고, 다른 학생의 기록을 고치는 것도 규칙에서 막힙니다.
- `firebase-config.js` 의 apiKey 는 공개되어도 괜찮은 값입니다(Firebase 웹앱의 정상 구조). 데이터 보호는 `firestore.rules` 가 담당합니다.
- **무료 한도**: 하루 읽기 5만 회·쓰기 2만 회. 한 학급이 매일 써도 넉넉합니다.
- **비밀번호 0으로 시작**: 비밀번호는 글자(문자열)로 저장하므로 `0123` 도 그대로 유지됩니다.
- 실시간 반영: 친구가 기록하거나 응원을 보내면 새로고침 없이 바로 화면에 나타납니다.

## 문제 해결
| 증상 | 확인할 것 |
|---|---|
| "Firebase에 연결하지 못했어요" | Authentication에서 **익명** 로그인을 켰는지 |
| 교사 로그인 후 "교사 계정이 아니에요" | `firebase-config.js` 의 `TEACHER_EMAIL` 철자 |
| 교사 화면에서 "권한이 없어요" | `firestore.rules` 의 이메일을 바꾸고 **게시**했는지 |
| 학생이 기록을 못 함 | 회차가 **종료** 상태인지 (회차 관리에서 다시 열기) |
